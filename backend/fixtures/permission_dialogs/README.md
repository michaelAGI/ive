# Permission dialog fixtures

These recordings exercise the terminal prompt parser. Home-directory names and
capture session identifiers are synthetic. Raw recordings retain their original
byte lengths, control sequences and cursor positions so redraw and selection
checks remain representative.

Before adding a capture, replace personal home-directory names with a
`fixture-`, `example-` or `test-` name, including wrapped and truncated copies.
Remove account details and credentials. Keep the replacement width identical
and update the rendered screen and manifest consistently. Run the prompt-menu,
session-prompt-guard and trust-attention tests after editing a recording.
