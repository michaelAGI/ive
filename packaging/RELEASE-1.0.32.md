IVE 1.0.32 — Device Hub

Connect an iPhone and open Devices in IVE. Choose Claude Code or Codex, then
select “Let an agent set it up”. The agent checks requirements, prepares the
bundled helper and guides pairing and Developer Mode. Trust, passcode and
Apple permission prompts still need your confirmation.

Assign a phone to an agent for screenshots, taps, swipes, text input and Home.
Stop setup or control from the Device Hub. Optional Full access uses the
selected agent's normal full-access mode on your Mac.

Ten editable task ideas cover photo duplicates, screenshot organization,
storage, receipts, reminders, calendar planning, Focus, travel preparation,
subscriptions and app testing. A read-only duplicate-photo report works on
an explicitly selected folder of exported photos; it never deletes files.

The guide is available in Devices and docs/device-hub-guide.md.

Requirements for optional iPhone control: Apple Silicon, macOS 27+, Xcode 27+
and iOS 27+. IVE's general macOS requirement remains 13.5+. This integration
uses Apple's private device input interfaces and still needs end-to-end
validation on a physical iPhone.
