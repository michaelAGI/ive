IVE 1.0.33 — Simpler iPhone connection

Devices now opens a compact connection dialog. Choose your iPhone and agent,
add an optional task, then connect. An iPhone that is already set up can start
control directly.

All ten task ideas are still available in a collapsible list. The screen preview
opens only when requested, and connection details and help stay one click away.
Agent permissions, task delivery and the stop controls remain available.

The dialog has been checked in light and dark themes, at desktop and narrow
widths, in Chromium and WebKit. Phone control requirements are unchanged:
Apple silicon, macOS 27+, Xcode 27+ and iOS 27+. Physical iPhone control still
requires device validation.

Personal capture paths were anonymized in the public source test fixtures.
The current app package was checked for bundled private state and credentials.
Historical Git author metadata and older source tags are outside that cleanup.
